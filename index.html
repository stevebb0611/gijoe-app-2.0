PROJECT INDEX · LOCAL

G.I. JOE COLLECTION // TRACKER

A personal inventory & condition tracker for a 700–800 figure vintage G.I. Joe collection. Open the live app below, review the frozen reference mockups screen by screen, or read the spec docs that define the data model, decisions and standards.

LIVE APP + REFERENCE MOCKUPS + SPEC DOCS VINTAGE FIELD-MANUAL UI
RUN IT LOCALLY ~60 SECONDS

The live app is a Vite React build served by a local Express + SQLite server. One command serves both the app and this page.

Build and start from the repo root (first time: npm install here and in web/): (cd web && npm run build) npm start
Open http://localhost:3000 for the live app. This page is at /index.html.
Front-end work: also run cd web && npm run dev for hot reload on :5173 (proxies /api to :3000). Restart npm start after server edits.

Heads-up: the live app reads and writes the real gijoe_collection.db. The reference mockups below pull React, Babel & fonts from CDNs, so keep an internet connection for them.
